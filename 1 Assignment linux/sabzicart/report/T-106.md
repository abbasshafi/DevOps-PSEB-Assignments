## Part A Question 1
Command: ls -la ~/sabzicart/secrets
Answer:
drwxrwxrwx  2 abbasshafi abbasshafi 4096 Oct 29 14:59 .
-rw-r--r--  1 abbasshafi abbasshafi   63 Oct 29 14:59 README.txt
-rw-r--r--  1 abbasshafi abbasshafi   37 Oct 29 14:59 api-tokens.txt
-rw-rw-rw-  1 abbasshafi abbasshafi   50 Oct 29 14:59 db-password.txt
-rw-r--r--  1 abbasshafi abbasshafi  112 Oct 29 14:59 deploy_key
In words:
- secrets folder (777): everyone can read it, enter it and create or delete files in it. This is the worst problem.
- README.txt, api-tokens.txt, deploy_key (644): only the owner can write; everyone on the machine can read them.
- db-password.txt (666): everyone can read AND write it.

## Part A Question 4
Command: find ~/sabzicart -perm -o+w
Answer: One extra item appears compared with task 2: /home/abbasshafi/sabzicart/webapp/current. It is a symbolic link (current -> releases/v2). Symlinks always show lrwxrwxrwx, so that "everyone can write" is meaningless; the permissions that count are those of the target. It can be ignored.

## Part B Question 7
Command: ls -ld /tmp ; chmod 1777 ~/sabzicart/tools/public-share
Answer: /tmp is drwxrwxrwt, so I copied that permission (1777). public-share is now drwxrwxrwt. Everyone can put files in it, but the sticky bit (the "t") means only a file's owner can delete or rename it.

## Part C Question 10
Command: ./backup-config.sh ; cat backup-config.sh
Answer: The error was:
cp: cannot stat '/home/kamran/sabzicart/webapp/config/app.conf': No such file or directory
The script has Kamran's home folder hard-coded in both paths (/home/kamran/sabzicart/...), and that folder does not exist for my user. The script does NOT tell the truth: it still prints "Config backup done." even though cp failed, because the echo is a separate command that always runs and the script never checks whether cp succeeded. ls -lt on the backups folder confirmed no new app.conf backup was created.


## Part C Question 11
Command: vim backup-config.sh   (then :%s#/home/kamran#/home/abbasshafi#g and :wq) ; ./backup-config.sh ; ls -l ~/sabzicart/backups/app.conf-$(date +%F).bak ; diff ~/sabzicart/webapp/config/app.conf ~/sabzicart/backups/app.conf-$(date +%F).bak
Answer: I replaced every /home/kamran with /home/abbasshafi (using # as the separator because the paths contain slashes). The script now reads:
cp /home/abbasshafi/sabzicart/webapp/config/app.conf /home/abbasshafi/sabzicart/backups/app.conf-$(date +%F).bak
Running it printed "Config backup done." and this time the file exists:
-rw-r--r-- 1 abbasshafi abbasshafi 401 Nov  1 11:05 /home/abbasshafi/sabzicart/backups/app.conf-2026-11-01.bak
diff printed nothing, so the backup is identical to app.conf.
