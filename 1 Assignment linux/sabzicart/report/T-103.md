## Part B: Active lines only (grep -vE '^ *#|^$' nginx-sample.conf)
```
worker_processes auto;
error_log /var/log/nginx/error.log warn;
events {
    worker_connections 1024;
}
http {
    sendfile on;
    keepalive_timeout 65;
    server_tokens off;
    access_log /var/log/nginx/access.log;
    gzip on;
    server {
        listen 80;
        server_name sabzicart.example www.sabzicart.example;
        return 301 https://$host$request_uri;
    }
    server {
        listen 443 ssl;
        server_name sabzicart.example;
        ssl_certificate     /etc/ssl/sabzicart/fullchain.pem;
        ssl_certificate_key /etc/ssl/sabzicart/privkey.pem;
        root /var/www/sabzicart;
        index index.html;
        location / {
            try_files $uri $uri/ =404;
        }
        location /images/ {
            expires 7d;
        }
        location /api/ {
            proxy_pass http://127.0.0.1:8080;
        }
        location /admin {
            deny all;
        }
        location = /wp-login.php {
            return 404;
        }
    }
}
```

## Part B: Answers (server_name, ports, proxy_pass, locations)
Command: grep -vE '^ *#' nginx-sample.conf | grep -E 'server_name|listen|proxy_pass|location'
Answer: server_name is sabzicart.example and www.sabzicart.example (port 80 block) and sabzicart.example (port 443 block). It listens on ports 80 and 443 (ssl). proxy_pass sends API requests (location /api/) to port 8080 (http://127.0.0.1:8080). There are 5 location blocks: /, /images/, /api/, /admin and = /wp-login.php.
Note: app.conf now uses port 9090, but nginx-sample.conf still proxies to 8080, so the proxy_pass port would need to be updated on a real server.
