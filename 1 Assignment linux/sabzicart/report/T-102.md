## Task 4: Create the structure
Command: mkdir -p organized/{images,invoices/{2025,2026},reports,scripts,logs,misc}
Answer: One mkdir created all 9 folders. -p creates parent folders as needed, and {a,b} is brace expansion done by bash before mkdir runs.

## Task 5: Delete temp files and junk first
Command: ls -l *.tmp ; ls -l '~$'* ; ls -l .DS_Store Thumbs.db ; rm *.tmp ; rm '~$'* ; rm .DS_Store Thumbs.db
Answer: Deleted 10 files: 6 .tmp, 2 ~$ lock files (~$monthly summary oct.docx, ~$sales-report-q4.xlsx), .DS_Store and Thumbs.db. 103 files left.
Why before moving the reports? The ~$ lock files end in .docx and .xlsx, so wildcards like *.docx and *.xlsx would match them and move them into reports/ as if they were real documents. Deleting them first keeps the wildcards clean.

## Task 6: Duplicate invoice

## Task 7: Move files with wildcards (part 1)
Command: mv *.jpg *.JPG *.png *.PNG ../organized/images/ ; mv invoice-2025-* ../organized/invoices/2025/ ; mv invoice-2026-* ../organized/invoices/2026/
Answer: 56 images (38 jpg + 14 JPG + 3 png + 1 PNG), 12 invoices for 2025, 9 for 2026. 25 files left in dump. Each extension needs its own pattern because Linux is case-sensitive.

## Task 11: Remove dump with rmdir
Command: ls -A dump ; rmdir dump-backup ; rmdir dump ; ls
Answer: rmdir dump succeeded silently because dump was empty. As a test, rmdir dump-backup failed with "Directory not empty" and deleted nothing.
Why is rmdir safer than rm -r? rmdir only removes an empty folder and refuses otherwise, so a file I missed can never be deleted by accident. rm -r deletes the folder and everything inside it without asking, so one overlooked file would be lost for good. If rmdir succeeds, that proves the folder was empty.
